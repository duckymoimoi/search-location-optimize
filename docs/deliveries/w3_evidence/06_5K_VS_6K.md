# 5k và 6k cùng protocol dev-lock

Cả hai khóa checkpoint bằng dev Hit@1, Gold chấm một lần sau lock. `tools/judge_devlock_summary.py` trả `call=continue` cho cả hai. Epoch giữ lại: 2.

6k trừ 5k trên Gold: Hit@1 +0.0075 (6 query), Hit@20 0, Hit@50 0, MRR@10 +0.0057. Cả hai đều cao hơn zero-shot Gold 0.84625. Mất rank 1 so với zero-shot: 16 query ở cả hai. q03 miss@20: 5k là 6, 6k là 5.

Quota giống nhau: random 2, lexical 1, dense 3, sibling 0. Slot weight v01/v02 = 1, v03–v06 = 0.25. Seed 42. Corpus v3. Gold overlap của pair = 0.

Dense negative không cùng file vector. 6k lấy từ `artifacts/embeddings/me5_small_v3` (`max_length` 128). 5k encode lại trên Kaggle, cùng model và `max_length` 128. Chênh Gold Hit@1 bằng 6 query không đủ để kết luận riêng hiệu ứng +1.000 POI.
