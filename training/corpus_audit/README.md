# corpus_audit

Scripts dựng / đếm corpus toàn quốc. **Data** nằm ở `data/vietnam/`.

| Script | Việc |
|---|---|
| `build_vietnam_poi_corpus.py` | Build `vn-poi-core-v1` |
| `extract_vietnam_admin_regions.py` | Admin regions |
| `count_vietnam_pois.py` | Đếm POI từ PBF |

Output: `data/vietnam/poi_corpus_v1/`, `admin_regions_v1/`, nationwide count reports.
