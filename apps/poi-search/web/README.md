# POI Search web demo

Vite + React + MapLibre. Lives under the runtime product `apps/poi-search`.

```powershell
..\scripts\start.ps1
```

Or from this folder:

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

Default: `VITE_USE_MOCK=0`, API via Vite proxy or `VITE_API_BASE_URL`. See `.env.example`.
